# DuckTales (Game Boy) Disassembly
This is a disassembly of DuckTales for the Game Boy.

To compile the rom, you must obtain graphical data and put it in Data/Graphics. You can use ExtractDuckTalesGBGraphicsData python script from "Scripts" folder to extract it from the ROM.

Additionally, you'll need to provide Nintendo Logo binary to make it work (hex $0104 through $0133).

To be assembled with RGBDS (Rednex Game Boy Development System).

Note that the disassembly currently only supports USA version of the game. Support for Japanese and European versions to be added later.
